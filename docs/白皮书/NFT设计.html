NFT设计

Hun 的 NFT 不是一张固定图片，而是由链上基因、品质、神秘标记和特性共同驱动的 3D 组合体。

当前 3D 方案采用 RGBA 权重遮罩：链上只记录稳定编号和资产属性，渲染系统再把这些编号映射为具体的 3D 部件、原始贴图、局部 Core 换色、材质、特效和静态渲染图。这样可以让合约保持稳定，同时保留每件美术资产自身的整体感，并让 UGC 和未来活动皮肤持续扩展。

实体部件默认保留原始 Base Color。mask.png 的 R/G/B/A 分别表示 primary、secondary、emissive、special 的局部影响强度；全零区域保持原色，非零区域保留原图明暗与纹理，只让色相、色度和发光跟随 Core。A 通道表示 special，不表示透明度。

核心原则​

Hun 的外观表达遵循一套分层规则：

基因决定“是什么”
品质决定“看起来有多强”
神秘标记决定“是否有特殊识别”
特性决定“额外异象/独立表现”

渲染时按固定顺序叠加：

  1. 基因选择 8 个部位的基础外观。
  2. core、阴阳、五行决定局部点缀、能量和材质主题，不覆盖部件的大部分原始设计。
  3. 品质给每个部位叠加强度层。
  4. 神秘标记给对应部位叠加特殊识别层。
  5. 特性作为全局或局部的独立视觉表现出现。

这意味着品质、神秘标记和特性不会随意改变一个部件“是谁”，而是在它之上增加表现力。Hun 的链上资产语义因此保持长期稳定。

8 个基因位​

Hun 的 3D 外观按 8 个基因位组织：

基因位名称表现方向
arms武器外部装备、悬浮武器、伴生物
aura灵气环绕能量、粒子、氛围光效
core核心基础形态、主色调、材质主题
crest造型流海、配饰、帽子、角等正面装饰
face脸部眼睛、嘴巴、面部表情与识别点
flame焰尾背部或尾部能量延展，强化轮廓和动态感
sound声音预留，用于未来声音风格或交互音效
pose姿态预留，用于待机动作、姿态或动画风格

每个基因位最多有 16 个普通设计，编号为 0-15。其中 0-7 是显性设计，8-15 是隐性设计。表达优先级为：

首选显性 > 次选显性 > 首选隐性

次选隐性不会直接表达，但仍可在遗传中保留价值。

事件皮肤​

每个部位还有一个事件皮肤字段，取值范围为 0-255：

  • 255 表示没有事件皮肤，使用普通基因表达出的部件。
  • 0-254 表示有效事件皮肤，使用该事件皮肤对应的部件或外观表现。

事件皮肤是外观表达层的“超显基因”。它可以覆盖普通组件的模型、贴图、mask、材质参数或特效表现，但不会改变阴阳、五行、品质、神秘标记和特性的资产语义。

因此，每个部位理论上可以表达：

16 个普通组件 + 255 个事件皮肤组件 = 273 种外观

事件皮肤适合承载节日活动、联名创作、社区纪念版本和特殊系列。它不会要求修改合约，只需要在资产 manifest 中登记对应资源。

品质表现​

品质是通用视觉增强层，不要求创作者为每个部件制作 6 套模型。

品质视觉方向
原始/灰哑光、低饱和、少发光、无粒子
普通/白干净基础材质，轻微高光
优秀/绿轻微边缘光，少量能量点
稀有/蓝更明显的 rim light，局部发光纹路
史诗/紫流动纹理、轻微粒子、部位周围能量拖尾
传说/橙强发光、动态脉冲、局部光晕、火星或轨迹

低品质应该表现为朴素，而不是廉价；高品质通过材质活性、动态表现和视觉密度体现成长感。

神秘标记​

神秘标记不是简单换色，而是一种特殊识别层：

  • 局部混沌描边。
  • 符文、裂纹或噪声纹理。
  • 小型环绕粒子。
  • 局部空间扭曲或边缘游离效果。

神秘部位仍保留原本品质强度，再叠加额外的异常感。这样可以避免神秘标记和品质色阶混淆。

特性表现​

特性是独立视觉系统，不占用 8 个基因位。它更像第 9 个外观层，根据 NFT 的 trait 字段额外解析。

稀有度表现方向
稀有度 1小型视觉符号
稀有度 2明显环绕物或光效
稀有度 3全局场域 + 动态表现
唯一特性专属全局视觉规则

MVP 阶段先建立 49 个 trait ID 的配置占位，只实现少数视觉样例。后续可逐步补充头顶符印、伴生微物体、全局 aura 变体、特殊 idle 动作、音效或背景场域。

创作者提交方向​

Hun 的 3D 资产体系支持社区创作。创作者不需要理解合约或前端实现，只需要按 RGBA 权重遮罩规范提交资源。

普通部件最少需要：

  • 一个明确的基因位，例如 arms、face 或 crest。
  • GLB 模型或特效配置。
  • 原始 Base Color 贴图。
  • 预览图。
  • 资源说明与授权信息。

需要跟随 Core 的部件应提供选择性 RGBA mask。主体结构、木材、皮革、金属和主要装饰原则上保留原图；mask 只覆盖能量、发光纹样、晶体、特殊高亮和少量点缀。正式 mask 由连续 RGBA 角色权重与创作者在 Blender 中校正的空间 selection 相乘，避免仅凭相近颜色误选主体材质。普通部件默认至少保留 70% 的有效 UV 原色。创作者不应把品质、神秘标记和特性直接做死进模型，因为这些会由渲染系统统一叠加。

事件皮肤提交时，需要说明对应部位、事件皮肤 ID、视觉主题、授权来源和预览图。事件皮肤可以覆盖普通部件外观，但仍应尊重该 Hun 本身的链上属性。

旧资产与兼容​

当前已有 GLB 是 MVP 的重要资产，会继续保留，不会因为 RGBA 权重遮罩升级而删除或改名。新的 manifest 会逐步登记旧资产，并为渲染器提供兼容映射。

兼容期内：

  1. 新资源按 RGBA 权重遮罩 manifest 提交。
  2. 旧 GLB 继续可被渲染和静态缓存使用。
  3. 已登记但缺少必需模型、Base Color 或 mask 的资源直接报错，不静默改变 NFT 外观。
  4. /rendered/*.avif 静态图继续作为 WebGPU 不可用时的展示兜底。

兼容期结束后，旧资产仍作为历史外观的一部分长期可渲染；结束的是旧映射格式的新增，不是旧 GLB 的存在。

对玩家的意义​

RGBA 权重遮罩让 Hun 的外观可以持续成长：

  • 同一套链上基因可以稳定解释，不因版本更新失去资产语义。
  • 品质、神秘标记和特性可以有清晰可感的视觉差异。
  • 事件皮肤可以承载活动和社区创作。
  • 创作者可以围绕部件、皮肤、材质和特效参与 Hun 世界构建。
  • 静态渲染图和实时 3D 可以共存，兼顾展示效率与互动体验。

最终目标是让每只 Hun 既是链上资产，也是可持续扩展的 3D 角色。
