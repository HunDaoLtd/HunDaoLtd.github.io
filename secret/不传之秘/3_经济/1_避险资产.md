# 避险资产

什么是避险资产？

人们一般会说黄金、国债。这是对的吗？在哪都成立吗？永远是对的吗？

其实这个问题根本就没有正确答案，因为**取决于你的「险」是什么**，这是基石。

其次是「资产」，它应在险情中提供**经济**（或生存）支持。



## 风险

世间风险繁异，「真正的避险资产」应当对抗最底层的风险，即**生存危胁**。

这样就算得上任何情况都避险了。

当今社会的生存危胁有哪些呢？假设你被全国通缉，股票、基金、债券、银行资产等全部被冻结；或者战乱之下国破家亡，法币变废纸、市场秩序无存、产权失去国家保障。此时，什么才是避险资产？



## 资产

资产是随着人类文明水平提高而变化的：

* 原始社会价值体现在即时使用性上，几乎没有金融属性；
* 古代社会对贵金属产生了共识，出现了真正意义上的金融避险资产；
* 现代是信用社会，境外信用资产也成为可选项，并且全球化使得避险不再局限于国境之内；
* 未来社会形态未知，避险资产将高度依赖于未来世界的技术路径和冲突形态。


| 社会形态 | 核心避险资产 | 价值基础 | 演变逻辑 |
| :--- | :--- | :--- | :--- |
| **原始** | 食物、工具、技能 | **使用价值** | 为直接生存 |
| **古代** | 黄金、粮食、土地 | **稀缺性 + 使用价值** | 出现财富储存和跨期交换 |
| **现代** | 美元、黄金、境外资产 | **全球信用 + 传统共识** | 全球化、金融化、数字化 |
| **未来** | 能源、数据、安全空间、技术 | **技术能力 + 生存保障** | 应对更高维度的风险与挑战 |



## 选择

了解了以上逻辑，什么是避险资产就清晰了。

所有人给的答案都是错误的，只有直面风险的你自己知道，你将会选择什么。
